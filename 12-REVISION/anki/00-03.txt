What does Boolean logic work with?	True and false values, commonly represented as 1 and 0 in digital systems. (00-03)
When does AND return 1?	Only when both input bits are 1. (00-03)
When does OR return 1?	When at least one input bit is 1. (00-03)
When does XOR return 1?	When the two input bits are different. (00-03)
What is overflow in an 8-bit unsigned value?	The result needs more than eight bits. If only eight bits are kept, the extra carry is lost; 255 + 1 becomes 0 in eight bits. (00-03)
How do you calculate an IPv4 network address?	Perform a bitwise AND between the IP address and its subnet mask. (00-03)
What is the wildcard mask for 255.255.255.192?	0.0.0.63. It is the inverse of the subnet mask. (00-03)
What is the broadcast address of 192.168.10.64/26?	192.168.10.127. The host bits are all set to 1. (00-03)
