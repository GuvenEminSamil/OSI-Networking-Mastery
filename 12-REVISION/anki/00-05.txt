What is a transistor used for in digital devices?	It can act as a very fast electronic switch and help build logic circuits. (00-05)
What is a logic gate?	A circuit that performs a Boolean operation on one or more input bits. (00-05)
What does volatile memory mean?	Its contents are lost when power is removed. RAM is volatile. (00-05)
What is RAM commonly used for in a Cisco device?	Working memory, including the active running configuration. (00-05)
What is flash commonly used to store?	The IOS image and other files. Flash is non-volatile. (00-05)
What is the difference between running-config and startup-config?	Running-config is the active configuration in RAM; startup-config is the saved configuration loaded at startup. (00-05)
Which command saves the active Cisco configuration?	copy running-config startup-config. (00-05)
