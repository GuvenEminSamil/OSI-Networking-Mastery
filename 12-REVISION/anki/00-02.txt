What is the base of the decimal number system?	10. It uses the digits 0 through 9. (00-02)
Which digits are used in binary?	Only 0 and 1. Binary has base 2. (00-02)
What is the decimal value of binary 1011?	11, because 8 + 2 + 1 = 11. (00-02)
How many bits does one byte contain?	8 bits. An octet is also exactly 8 bits. (00-02)
How many bits are represented by one hexadecimal digit?	4 bits, also called one nibble. (00-02)
What is the maximum decimal value of an 8-bit octet?	255, because 11111111 in binary equals 255. (00-02)
What is the theoretical MB/s equivalent of 100 Mbps?	12.5 MB/s. Divide by 8 because one byte contains eight bits. (00-02)
What is the difference between SI and IEC prefixes?	SI uses powers of 1,000 (kB, MB, GB); IEC uses powers of 1,024 (KiB, MiB, GiB). (00-02)
