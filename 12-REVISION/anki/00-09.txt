How many layers are in the OSI model?	Seven: Physical, Data Link, Network, Transport, Session, Presentation, Application. (00-09)
How many layers are in the common TCP/IP model used in this course?	Four: Link, Internet, Transport, Application. (00-09)
What does PDU mean?	Protocol Data Unit; the name given to the data handled at a particular network layer. (00-09)
What are common PDU names from Layer 4 down to Layer 1?	TCP segment (UDP datagram), packet, frame, bits. (00-09)
What is encapsulation?	Adding control information such as headers as data moves down the layers before transmission. (00-09)
Which Ethernet header field identifies IPv4 or IPv6 payloads?	EtherType. IPv4 uses 0x0800; IPv6 uses 0x86DD. (00-09)
Which command displays a Cisco router's routing table?	show ip route. (00-09)
