What does NIC stand for?	Network Interface Card (or Network Interface Controller); it connects a computer to a network. (00-07)
What is a network driver?	Software that allows the operating system to communicate with a hardware device. (00-07)
What is DMA?	Direct Memory Access; it lets hardware transfer data to or from RAM without the CPU copying every byte. (00-07)
What is a buffer?	A temporary memory area that holds data while it waits to be processed. (00-07)
What can happen when a receive buffer is full?	New incoming frames may be dropped because no free buffer space is available. (00-07)
What does show interfaces help you inspect on Cisco devices?	Interface status, traffic counters, errors, and drops. (00-07)
Why might a local capture show an incorrect checksum on an outgoing packet?	Checksum offload may calculate the final checksum in the NIC after the capture point. (00-07)
