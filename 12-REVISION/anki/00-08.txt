What is a LAN?	A Local Area Network; a network covering a limited area such as a home or office. (00-08)
What is a WLAN?	A Wireless Local Area Network, usually using Wi-Fi. (00-08)
What is the main role of a Layer 2 switch?	To forward Ethernet frames within a local network using MAC addresses. (00-08)
What is the main role of a router?	To forward IP packets between different IP networks using its routing table. (00-08)
What is the difference between bandwidth and throughput?	Bandwidth is link capacity; throughput is the actual successful data rate. (00-08)
What is jitter?	Variation in packet delay. It can affect real-time voice and video. (00-08)
Which addresses normally change when a router forwards a packet to the next Ethernet link?	The source and destination MAC addresses change. The IP addresses normally remain the same unless NAT is used. (00-08)
