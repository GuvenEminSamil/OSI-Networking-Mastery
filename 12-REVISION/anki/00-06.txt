Why do bytes need an agreed interpretation?	The same bytes can represent different things. A protocol or file format defines their meaning. (00-06)
How many values can an 8-bit unsigned field represent?	256 values, from 0 to 255. (00-06)
What is the maximum value of a 16-bit unsigned field?	65,535, because 2^16 - 1 = 65,535. (00-06)
What does big-endian mean?	The most significant byte comes first. (00-06)
What is network byte order?	Big-endian byte order used for multi-byte numeric fields in Internet protocols. (00-06)
What is a character encoding?	A rule that maps characters to numeric values and bytes, such as ASCII or UTF-8. (00-06)
Why is a file signature useful?	It is a recognizable byte pattern that can help identify a file's actual format, unlike a file extension alone. (00-06)
