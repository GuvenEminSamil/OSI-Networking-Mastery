# OSI Networking Mastery — CCNA 200-301 v1.1

> **Target:** Cisco CCNA 200-301 v1.1. The syllabus version is fixed at v1.1; the course is not being migrated to v2.0.
>
> **Study language:** English.
>
> **Start here:** [START-HERE.md](START-HERE.md)

## Purpose

This repository is a structured learning path for understanding how computer networks work, how to configure them, and how to troubleshoot them.

The goal is not simply to memorize the OSI layers or Cisco commands. The goal is to understand the concepts well enough to apply them to practical network situations and CCNA exam questions.

## Teaching standard

- Use clear, beginner-friendly English.
- Explain every new technical term when it first appears. Never assume prior knowledge.
- Explain a prerequisite term before relying on it.
- Use practical examples and simple scenarios.
- Keep lesson length proportional to topic complexity.
- Avoid unnecessary academic or scientific depth.
- Include troubleshooting examples and Packet Tracer practice when they add real value.
- Use knowledge-check questions with answers and explanations.
- Verify calculations, command examples, question wording, and answer keys before publishing.

## How to use the repository

1. Start with [START-HERE.md](START-HERE.md).
2. Follow the lesson sequence shown there and in [PROGRESS.md](PROGRESS.md).
3. Read a lesson in manageable sections.
4. Try the knowledge-check questions before opening their answers.
5. Complete useful practical work when provided.
6. Use flashcards only when they help you review; they are optional.
7. Record actual lesson completion only in [PROGRESS.md](PROGRESS.md).

There is no fixed daily schedule or required number of study hours. Progress is based on understanding and completion, not dates.

## Repository structure

- `00-FOUNDATIONS/`: number systems, Boolean logic, electricity, data representation, computer architecture, networking fundamentals, and layered models.
- `01-PHYSICAL-LAYER/`: physical media, signals, cabling, and Ethernet physical-layer topics.
- `02-DATA-LINK-LAYER/`: Ethernet frames, MAC addressing, switching, VLANs, and related technologies.
- `03-NETWORK-LAYER/`: IPv4, IPv6, subnetting, routing, and related protocols.
- `04-TRANSPORT-LAYER/`: ports, sockets, TCP, and UDP.
- `05-SESSION-LAYER/` and `06-PRESENTATION-LAYER/`: session, data representation, encryption, and related concepts.
- `07-APPLICATION-LAYER/`: DNS, DHCP, HTTP(S), SSH, and other application protocols.
- `08-CROSS-LAYER-COMMUNICATION/`: end-to-end scenarios combining multiple layers.
- `09-PACKET-TRACER-LABS/`: guided networking practice and full labs.
- `10-QUESTION-BANK/`: topic-based and comprehensive questions.
- `11-TROUBLESHOOTING/`: methods, tools, and case studies.
- `12-REVISION/`: optional spaced review and flashcards.
- `13-CCNA-EXAM-PREPARATION/`: exam readiness and coverage checks.
- `14-SECURITY-FUNDAMENTALS/` and `15-NETWORK-OPERATIONS-AUTOMATION-AI/`: security, operations, and automation topics included in the CCNA scope.
- `16-REAL-HOST-LABS/`: optional practice on real operating systems and with code.

Only lessons that exist in the repository should be treated as published study material. Planned topics in the curriculum are not completed lessons until their files are created and reviewed. The first Physical Layer lesson, 01-01, is now published; later Physical Layer lessons are still being prepared.
