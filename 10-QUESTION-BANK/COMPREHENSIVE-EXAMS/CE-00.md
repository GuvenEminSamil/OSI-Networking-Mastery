# CE-00 — Diagnostic Test

> **Purpose:** Historical baseline assessment. This test was based on the 25 questions in Section 19 of the earlier OSI notes (`USR-OSI-NOTES`). The separate answer key includes explanations and links to the current curriculum.  
> **Time:** 40 minutes | **Score:** 40 points  
> **Important:** This is a starting-point diagnostic, not a mastery test. It has already been completed and scored; use it as a record of your starting level rather than as a required repeat exercise.

## How to Use the Test

1. For a fresh attempt, answer without consulting lesson files, the internet, or the answer key.
2. Mark uncertain answers with `?`.
3. Questions in Section A are worth 1 point each. Questions in Sections B and C are worth 2 points each.
4. After scoring, note the relevant lesson file for each incorrect or uncertain answer.

## Section A — Basic Knowledge (1 point each)

1. How many layers are in the OSI model?
2. What are the names of the highest and lowest OSI layers?
3. At which OSI layer does TCP operate?
4. At which OSI layer is the IP address used?
5. Which OSI layer is associated with MAC addresses?
6. At which layer does a router primarily operate?
7. At which layer does a switch primarily operate?
8. What Protocol Data Unit (PDU) is created when an IP header is added before a TCP segment?
9. An Ethernet frame is the PDU of which OSI layer?
10. What is the difference between encapsulation and decapsulation?

## Section B — Scenarios (2 points each)

11. You connect an Ethernet cable to your computer, but the link light does not turn on. Which OSI layer should you check first, and why?
12. Your computer can access the Internet but cannot ping another computer on the same network. What might cause this, and which layers would you investigate?
13. You cannot access a website, but you can ping `8.8.8.8`. Which layer or service might be involved?
14. A computer has IP address `192.168.1.10`, and its router has IP address `192.168.1.1`. When the computer sends data to `8.8.8.8`, what should the frame's destination MAC address be?
15. What does a switch do when it cannot find the destination MAC address in its MAC address table?
16. Under normal routing conditions, what information does a router change when forwarding an IP packet to another network?
17. Which three messages form the TCP three-way handshake?
18. What are the four stages a computer uses to obtain an IP address through DHCP?
19. A user connects to a website using HTTPS. What security purposes does TLS provide?
20. A switch has VLAN 10 and VLAN 20. A computer in VLAN 10 needs to communicate with a computer in VLAN 20. What mechanism is required?

## Section C — Deeper Reasoning (2 points each)

21. A computer sends a packet to a remote web server:

    ```text
    Source IP: 192.168.1.10        Destination IP: 203.0.113.20
    Source MAC: AA:AA:AA:AA:AA:AA  Destination MAC: BB:BB:BB:BB:BB:BB
    ```

    After the packet passes through a router, a new frame is created. During normal routing, why can the MAC addresses change while the IP addresses remain the same?

22. TCP provides reliable delivery. Why do some online games prefer UDP?

23. Broadcast frames continuously circulate in a network and performance becomes poor. What Layer 2 problem might be occurring? Which protocol helps prevent it?

24. A router's routing table contains `192.168.0.0/16` and `192.168.1.0/24`. Which route is selected for destination `192.168.1.10`, and why?

25. A computer has address `192.168.1.10/24`. Why does it try to learn the destination computer's MAC address when sending to `192.168.1.50`, but first learn the default gateway's MAC address when sending to `8.8.8.8`?
